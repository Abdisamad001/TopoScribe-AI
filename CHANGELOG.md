# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-13

### Added

- Initial stable release.
- 4-Agent LangGraph workflow (Planning, Topology, Configuration, Validation).
- Dual-tier LLM architecture with Groq primary tier and automated diagnostic escalation gate.
- Deterministic guardrails for RFC 1918 addressing, VLAN allocation, and Cisco IOS CLI generation.
- Next.js and React Flow interactive workspace.
